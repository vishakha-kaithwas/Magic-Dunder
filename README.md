# 🪄 Magic-Dunder

Welcome to **Magic-Dunder** — a Python repository dedicated to exploring and implementing **Magic (Dunder) Methods** 🧠  

These are special methods in Python that start and end with double underscores (`__`), like `__init__`, `__str__`, or `__add__`.  
They define how objects behave with built-in functions and operators — making Python truly *“magical”* ✨  

---

## 🚀 About the Repository

This repository contains beginner to intermediate-level **Python projects and examples** that demonstrate the use of:
- **OOP Concepts** (Classes, Inheritance, Encapsulation)
- **Operator Overloading**
- **Custom Object Behavior**
- **Magic (Dunder) Methods**

Each file focuses on one or more dunder methods with clear, commented examples.

---

## 🧩 What You’ll Learn

| Magic Method | Description |
|---------------|--------------|
| `__init__` | Initializes objects (constructor) |
| `__str__` | Controls how an object is printed |
| `__repr__` | Returns developer-readable string |
| `__eq__` | Compares two objects using `==` |
| `__len__` | Defines behavior for `len(object)` |
| `__add__` | Enables addition using `+` operator |
| `__sub__`, `__mul__`, etc. | Arithmetic operator overloading |
| `__getitem__`, `__setitem__` | Enables indexing like lists/dicts |
| `__call__` | Makes an object callable like a function |
